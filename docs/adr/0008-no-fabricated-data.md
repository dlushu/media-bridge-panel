# ADR-0008 不编数据：不知道就空字段，没有数据就如实回空

- 状态：已采纳
- 相关：[emby-compat.md](../emby-compat.md) · [0007](0007-emby-dto-shape.md) · [0009](0009-unauthenticated-empty-responses.md)

## 背景

真机 Emby 的响应中存在一批本项目**不掌握**的字段（文件创建时间、探测能力、流协议与缓冲细节、
全库统计等）。照抄真机的取值可以让响应看起来"更完整"，但那是把未知值伪装成已知值。
同类问题出现在"本项目没有这类数据"的端点（观看历史、类型清单、条目计数）上：
可以返回 `501` 表示未实现，也可以用上游榜单数字充当"库统计"。

## 决定

**不掌握的值一律不填**，需要表达"没有数据"的端点**如实返回空**（空数组、计数为 0），
既不返回 `501` 充数，也不编占位数据。

据此删除过 7 个照抄真机的字段（`SupportsProbing`、流级 `Protocol`、`TimeBase`、
`IsAnamorphic`、`IsInterlaced`、`IsHearingImpaired`、`ExtendedVideoType`）；
`VideoRange` 与色彩三元组改为"源明确标注时才显示"。

唯一一处近似处理**明确记录在案**：`DateCreated` / `DateModified` 使用 TMDB 发行日期
（真机给的是**文件**的创建时间，本项目没有文件）；取不到时不给这两个字段。

## 理由

编造的数据比空值更糟：客户端会把假清单、假统计当作事实展示给用户，且无法与真实数据区分。
空值至少是诚实的，且用户能据此判断"这里本该有数据但拿不到"。

## 备选方案

- **照抄真机值充数**：响应更"像"真机，但引入无法解释的假数据。
- **返回 `501` 表示未实现**：客户端会在界面上报错；对"确实没有数据"的语义而言，空列表更准确。

## 后果

- 失败语义同步遵循该原则：上游给出状态码就照搬（`401` / `403` / `404` / `429` / `5xx`），
  网络层归类为连不上 `502`、超时 `504`、未配置 token `500`、id 不合法 `400`；**不做"假成功"**。
- 某些客户端可能因此显示较少字段，这是有意取舍。
- 与 [ADR-0007](0007-emby-dto-shape.md) 的边界：结构字段必须齐（可以给空数组或零值占位），
  但**取值**不掌握就不填。
