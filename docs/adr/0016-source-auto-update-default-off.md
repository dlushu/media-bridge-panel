# ADR-0016 源自动更新默认关闭

- 状态：已采纳
- 相关：[auto-update.js](../../server/modules/source/auto-update.js) · [0015](0015-source-bundle-integrity.md)

## 背景

面板可以按间隔检查所托管源的新版本：比对远端 `index.js.md5`，有变化则下载并校验，
**若该源正在运行则自动重启它**。重启会打断正在进行的播放请求。

## 决定

自动更新**默认关闭**，由用户显式开启并设置间隔（默认 `12` 小时，取值 1~168）。
开启后的行为约定：

- 面板启动后**延迟 2 分钟**才执行第一次检查（等自身先稳定）。
- **单飞**：上一次未跑完不重入；手动触发撞上定时任务时返回 `409`。
- **跑完才排下一次**，不会堆积。
- 单个源失败**只记日志**，下一轮再试，不因此修改设置或停用该源。
- 校验未通过的源不代为恢复（见 [ADR-0015](0015-source-bundle-integrity.md)），如实报告状态。

## 理由

自动重启的收益（保持源为最新）与代价（打断播放）需要由部署者权衡，不适合作为默认行为替用户决定。

## 备选方案

- **默认开启**：用户无需关心更新，但会在不知情的情况下被打断播放。
- **不提供该功能**：每次升级都需手动操作，对长期运行不友好。

## 后果

- 未开启时，更新源需要手动点击「更新」（行为与自动更新完全一致）。
- 设置存放在 `data/settings/source.json` 的 `autoUpdate` / `autoUpdateHours`；
  修改后按新间隔重新排期。
- 常态开销：每个源每轮两个小请求（探测 md5），未变化时不会下载源包。
